# Component inventory checklist

When expanding the Components section, look for:

- Buttons / CTAs (primary, secondary, text, disabled, hover, focus)
- Links (inline, nav, footer)
- Form fields (text, select, checkbox, radio, validation)
- Navigation (header, mobile menu, breadcrumbs, tabs)
- Cards / tiles / feature blocks
- Hero / banner / page intro
- Alerts / toasts / banners
- Modal / dialog / drawer
- Tables / data lists
- Accordion / disclosure
- Media (image, video, icon-only controls)
- Footer / utility chrome

For each component document:

1. Anatomy (parts)
2. Variants
3. States
4. Key CSS hooks / class names (evidence)
5. Notes for implementers
