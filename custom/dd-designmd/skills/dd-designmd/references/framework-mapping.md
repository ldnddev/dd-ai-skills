# ldnddev Framework mapping

Always include a mapping table from **observed** UI to Framework components.

## Common maps

| Observed | Candidate Framework |
|----------|---------------------|
| Header / site nav | `dd-header` |
| Hero | `dd-hero` |
| Card grid | `dd-card` |
| Footer | `dd-footer` |
| Alert / notice | `dd-alert` |
| Section layout | `dd-section` / grid utilities |
| Buttons | Framework button patterns |

## Rules

- Map intent/structure, not pixel perfection.
- Use **gap / no match** when Framework has no analogue.
- Do not rewrite the site into Framework HTML in this skill — mapping only.
- For authoring details, point agents to the `dd-framework` skill.
